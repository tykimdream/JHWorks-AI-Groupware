## 문제와 구현 범위

기존 첫 화면은 결재 목록으로, 사용자의 다음 행동과 AI 업무 지원 경험을 충분히 드러내지 못했다.
로그인/공개 체험의 첫 진입을 업무 홈으로 연결하고, 실제 API 데이터 기반 현황·최근 문서·다음 할 일을 제공한다.
사용자의 요청과 예시를 초안 스튜디오에 전달하고 추가 질문→규정 근거/미리보기→명시적 저장→문서 상세로 이어진다.
AI 실패 시 요청을 유지하며 재시도 또는 직접 작성으로 이동할 수 있다.

색상·간격·타이포·반경·모션은 `apps/web/src/app/workspace.css`의 토큰을 사용한다.
공통 탐색/프로필/현재 위치와 아이콘을 공유하고, 모바일 배치와 가시적 키보드 포커스·모션 감소 설정을 지원한다.
홈에서 Cmd/Ctrl+J는 요청 입력에 포커스, Cmd/Ctrl+Enter는 초안 화면 이동이다. 이동만으로 AI를 호출하거나 저장하지 않는다.
결재 목록은 scope 변경 시 기존 요청을 취소하고 중단된 응답을 무시하며, 같은 탭 재클릭으로 무한 로딩되지 않는다.

## 로컬 실행

브라우저 fixture는 임시 SQLite와 합성 계정만 사용하며 원격 DB나 유료 AI를 호출하지 않는다.
첫 터미널에서 `cd apps/api && uv run uvicorn tests.e2e_server:app --host 127.0.0.1 --port 8100`,
다른 터미널에서 저장소 루트 기준
`NEXT_PUBLIC_API_URL=/api/v1 API_PROXY_TARGET=http://127.0.0.1:8100 pnpm --filter @jhworks/web exec next dev --hostname 127.0.0.1 --port 3100`을 실행한다.
`http://localhost:3100`에서 합성 Demo 로그인을 선택한다.
출장 예시→초안 준비→종료일 질문에 ‘당일 출장입니다.’→답변 반영→미리보기 확인→저장으로 재현한다.
fixture의 모델 출력은 scripted 응답이며 결과 화면에 시뮬레이션임을 표시한다. 임시 DB는 서버 종료 시 사라진다.
이 서버를 배포하거나 실제 인증정보/회사 자료를 넣지 않는다.

## 남은 제품 작업

이미 지출한 비용의 정산은 현재 모델에서 EXPENSE 의도로 구분하지만 저장은 지원하지 않는다.
일반/출장으로 몰래 바꾸지 않고 미지원 안내를 유지한다. 경비 정산 데이터 모델·지출 내역/증빙·규정 검증을
다음 업무 단위로 설계해 구현해야 사용자가 제시한 ‘CES 출장 17만원 정산’ 대표 요청을 완결할 수 있다.
다음 할 일은 실제 문서 상태로 만든 제안이며, 출장 종료/미정산·중복 지출 탐지 등 선제 Agent는 아직 없다.
공개 체험 AI off 정책을 유지하며 비용 제한을 갖춘 실제 모델 연결·품질 평가와 공개 도메인 배포도 남아 있다.
이번 작업에서 GCP 자원·IAM·예약·삭제 설정은 변경하지 않았다.

## 최종 UI 리뷰 보완 (2026-10-24)

업무 요청 원문을 URL 쿼리로 전달하지 않는다. 직원별 sessionStorage에 임시 보관하고 초안 화면 진입 시 소비하며 로그아웃 시 정리한다. 저장소 사용 실패 시 입력을 유지하고 수동 작성 경로를 안내한다. URL·방문 기록·접근 로그에 요청 원문이 남지 않는 경로를 브라우저 테스트로 확인했다. 경비/누락·중복 점검은 후속 구현 문서 기준이며 실제 유료 AI와 공개 도메인 연결은 아직 완료되지 않았다.
