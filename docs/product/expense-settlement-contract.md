# 경비 정산 대표 업무 계약 — M0-01

기준: 2026-10-25. 대표 대상은 지출 정보를 정리하는 작성자와 사실·근거를 검토하는 결재자다.
정책·조직·직원·지출은 합성 자료이며 실제 회사의 성과나 실제 CES 일정으로 해석하지 않는다.

## 고정 과제와 알려진 사실

AI 평가의 기준일은 2026-08-25, timezone은 Asia/Seoul이다. 상대 날짜는 이 기준으로 해석한다.
공개 수동 체험에서는 실제 서버 날짜를 사용하므로 과거 절대 지출일을 입력한다.

- 최초 요청: “이번 CES 출장에서 쓴 17만원 경비 정산 결재를 준비해줘.”
- 아직 모르는 정보: 실제 지출일·사용처·비용 구분·업무 목적·증빙 참조.
- 후속 사실: 2026-08-24 / 코레일 / 교통비 / CES 협력사 방문 / RCP-CES-001.
- 실제 지출일을 출장 기간으로 대신하거나 지출 금액을 예상 출장비로 바꾸지 않는다.
- 제목·본문은 제공한 사실로 요약할 수 있지만 사용처·날짜·금액·목적·증빙 사실을 만들지 않는다.
- 증빙 참조는 문자열이다. 파일을 첨부했다는 말이 원본 업로드·진위 확인을 의미하지 않는다.

## 상태·행동과 성공 조건

| 단계 | 사용자 행동·화면 | 서버/AI 계약 | 근거 |
| --- | --- | --- | --- |
| 시작 | 공개 홈에서 직접 경비 작성, 또는 AI 가능 환경에서 자연어 입력 | 공개 AI는 현재 OFF. 수동 경로 유지 | `/`, `/approvals/new?type=EXPENSE`, `/approvals/ai-draft` |
| 추가 질문 | 빠진 사실을 입력 | `prepare`는 NEEDS_INPUT/질문을 반환하고 업무 문서를 생성하지 않음 | `POST /api/v1/approval-draft-assistant/prepare` |
| 미리보기 | 추출한 사실·정책 근거·저장할 내용을 확인 | 충분한 사실이면 PREVIEW와 서명된 확인 토큰. 조회된 규정의 상태·버전·출처 구분 | 기존 초안·정책 검색 서비스 |
| 초안 저장 | 직접 저장 또는 AI 미리보기의 저장을 명시적으로 확인 | 직접 작성의 초안은 미완성 허용. AI confirm은 actor/hash/token 검증과 멱등 저장 | `POST /approvals`, `POST /approval-draft-assistant/confirm` (API prefix 생략) |
| 보완 | 누락/중복 후보의 원문과 입력 내용을 확인·수정 | 누락/미래 날짜/양수 금액 검증, 권한 있는 중복 후보만 반환. 중복 확정·자동 반려 아님 | `expense-checks`, `expense-insights`, 수정 API |
| 제출 | 문서·금액·버전 확인 후 제출 | 작성자·현재 관리자·상태·필수 사실·version 재검증 | `POST /api/v1/approvals/{id}/submit` |
| 결정 | 역할 전환 후 담당 문서에서 승인/반려 확인 | 지정 결재자만 결정, version/상태 검증, 이력 보존 | approve/reject 명령 |
| 결과·재작성 | 작성자에게 결과 표시, 반려 시 수정 후 재제출 | 반려→초안 재작성, 과거 회차 보존 | revise 명령과 기존 상태 전이 |

## 실패 조건

| 상황 | 기대 행동 | 기존 검증/남은 범위 |
| --- | --- | --- |
| 모르는 사실 | null 유지와 추가 질문, 문서 자동 저장 없음 | 기존 prepare 서비스·회귀, 모델 사실 추출은 아직 확대 검증 전 |
| 0원/미래 지출일 | 사실을 임의 변경하지 않고 서버에서 보완 요청·제출 거절 | expense_validation, 경비 API 회귀 |
| 후속 정정 | 제공된 최신 사실을 구조화 | 평가셋의 정정 사례. 실제 모델 정확도는 not-run |
| 잘못된 원화 환산 | 환율 없는 외화 금액을 KRW로 지어내지 않음 | 새로운 실제 모델 필수 평가 사례 |
| 정책 근거 부재 | 검색 상태·근거 부재를 표시, 준수를 보증하지 않음 | 정책 검색/검토 회귀. 새 대표 경비 화면 검증은 후속 |
| 모델 장애 | 오류와 직접 작성 경로, 업무 문서 생성 없음 | 기존 provider failure/API·브라우저 회귀 |
| 확인 토큰 변조/다른 사용자 | 거절, 무변경 | 기존 hash/actor 회귀 |
| 문서 버전 경합 | 덮어쓰지 않고 conflict 안내 | 기존 승인·수정 서비스 회귀 |
| 체험 만료/한도 | 세션·예산 경계를 유지, 입력 회복 범위 안내 | 기존 방문자 회귀, 입력/탐색 맥락 개선은 M3 |
| AI 비용 소진 | 명확한 안내와 수동 경로 | 공개 AI 예산은 M2-02/03, 현재 미구현·미공개 |

## 이번 완료와 다음 차이

M0-01은 이 문서로 대표 과제·다음 행동·구현 경계와 평가 기대값을 고정한다.
M2-01은 기존 추출 사례 6개를 36개로 확장하고 평가 데이터·채점·모델 gate의 offline 계약을 검증한다.
서버의 질문/정책/저장/권한 계약은 기존 회귀를 재사용하며 자연어 추출 평가와 별도로 기록한다.

실제 모델 추가 호출·공개 AI·사람의 완료율 측정은 이 변경으로 수행하지 않는다.
사용자에게 아직 어떤 설명이 어려운지는 [경비 사용성 실험](../portfolio/expense-task-study.md)에서 검증한다.
