# 경비 정산 API와 사전 점검 계약

EXPENSE 의도를 출장 신청으로 바꾸지 않고 지출일·사용처·비용 구분·업무 목적·증빙 참조를 저장한다.
기존 EXPENSE enum과 JSON details를 확장하므로 새 DB migration은 필요하지 않다.
불완전한 수동 초안은 허용하고, AI 미리보기·제출·검토는 같은 필수 지출 검증을 사용한다.
양수 실제 금액과 Asia/Seoul 기준 미래가 아닌 지출일을 요구한다. AI의 상대 날짜 기준도 Asia/Seoul이다.
확인 토큰의 미리보기 서명·명시적 확인·중복 저장 멱등성과 서버 권한/버전 검증을 재사용한다.

영수증 참조는 원본 문서 위치 정보이며 attachmentMetadata로 바꾸지 않는다.
검색 질의에 실제 지출 정보와 영수증 요건을 포함한다. 증빙 참조가 있어도 필요한 원본 첨부 누락 검토를
통과시킨 것으로 취급하지 않는다. 실제 업로드/진위 확인/지급은 별도 기능이다.

## 읽기 전용 점검

- GET `/api/v1/approvals/expense-insights`: 내 초안·결재 중 경비 최근10개를 점검한다.
- GET `/api/v1/approvals/{id}/expense-checks`: 조회 가능한 경비의 버전·누락 필드·중복 근거를 반환한다.

중복 후보는 같은 작성자·지출일·앞뒤 공백을 제거한 사용처·금액이 같은 다른 경비다.
반려 문서는 제외하며 실제 중복이라고 확정하지 않는다. 근거는 조회 가능한 최근3개까지만 표시하고,
추가 근거/추가 점검 대상 유무를 별도 반환한다. 결재자는 미배정 초안을 근거로 받지 않는다.
기존 목록과 점검은 동일한 작성자/결재선 권한·방문 공간 경계를 사용한다. 점검은 자동 제출·수정·반려를 하지 않는다.
코드의 규칙으로 판단하며 이 경로에서 LLM은 호출하지 않는다.

## 검증 범위

저장·수정·제출·승인, 누락/미래일/0원 차단, 서명·변조·중복 확인, 원본 증빙 구분,
권한·체험 공간·미배정 근거 비노출·응답 상한·읽기 전용 회귀를 포함한다.
전체 로컬 API507 passed/PG29 skipped 이후 한국 날짜 경계 회귀를 추가했다.
정확한 PR head의 전체 회귀·PostgreSQL·컨테이너 검증은 CI 결과를 기준으로 한다.
실제 모델 품질·대용량 성능·원격 배포·공개 여부를 이 변경의 완료로 주장하지 않는다.
