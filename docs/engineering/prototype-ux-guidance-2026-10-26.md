# 프로토타입 첫 사용 안내 보완 — 2026-10-26

공개 프로토타입 검증에서 AI가 꺼진 근태 화면이 일반 결재 작성으로 안내하고, 내 조직의 합성 식별자가 본문을 차지하는 문제를 확인했다. 이번 변경은 기존 업무로 이어지는 경로와 표시만 보완한다.

## 변경한 동작

- AI 사용 안내는 현재 화면의 업무를 기준으로 한다. 근태에서는 같은 화면의 휴가 후보 조건으로 이동해 포커스를 옮긴다. 경비 초안 화면에서는 실제 호출 없는 예시와 직접 작성 중 선택한다. 업무 조회는 체험 안내로 이어진다.
- 설정 조회 중·조회 실패·기능 비활성 상태를 구분한다. 조회 실패는 alert, 로딩은 status로 알리며 조회 실패를 정상 OFF로 설명하지 않는다. 기능 활성 시 기존 AI 화면을 그대로 사용한다. aiCapabilities가 없는 기존 API 응답도 비활성 경로로 처리한다.
- 방문 공간의 `체험 조직 <32자리 hex>`만 ‘내 체험 조직’으로 줄여 표시한다. 일반 부서명은 그대로 표시한다. 조직 ID·캐시·API 값·권한은 바꾸지 않는다.
- 이메일과 원본 부서명은 ‘원본 프로필 정보’에서 펼쳐 볼 수 있다. 화면에 없는 부서나 임의 회사 정보를 만들지 않는다.
- 휴가 후보의 행동 이름을 ‘이 날짜로 휴가 결재 작성’으로 통일한다.

JHW의 흰색 surface `#ffffff`, canvas `#f7f8fc`, 본문 `#202735`, 보조 `#626b7a`, 경계 `#e5e7ee`, 강조 `#6554cf`와 기존 글꼴을 유지한다. 안내는 기존 화면의 단일 작업 구역에 왼쪽 정렬하며 새 장식 카드나 자동 팝업을 추가하지 않는다.

## 검증 범위

기존 AI capability 회귀에서 legacy 응답·기능별 gate·설정 실패·비용 제한을 확인한다. 근태 대체 링크의 URL·실제 조건 폼 포커스, 조직 원본 펼침, PC/모바일 가로 넘침·접근성, 경비 작성·휴가 기존 흐름을 함께 확인한다. 사용성 개선 효과의 수치나 신규 사용자 완료율은 아직 측정하지 않았다.

제품 소스의 PR·CI 통과와 공개 반영은 구분한다. 공개 AI·키·예산·API·DB·IAM·자동 정리 설정은 이번 변경 범위가 아니다.
