# 가상 사례 기반 기안과 개인정보 경계

일반 결재 초안은 24건의 가상 기안을 참고한다. 인터뷰, 업무 결과, 구매, 프로젝트, 협조 요청, 계약, 장애, 예산, 권한 등 여러 유형을 포함하며, 사례의 구체적 값은 자리표시자다. 검색된 사례는 화면에서 확인할 수 있다. 실제 결재 문서의 인덱싱이나 접근 권한 제어는 구현되지 않았다.

## 초안 입력과 외부 전송

초안 생성과 반려 경비 수정 제안에서는 사용자의 요청·답변·반려 의견의 모든 공백 외 텍스트를 서버에서 불투명한 토큰으로 치환한다. 원문 대응표는 요청 처리 중 서버 메모리에만 두고 모델 요청 JSON에서 제외한다. AI 응답에서 토큰을 서버 안에서 원래 값으로 되돌린다. 명시된 경비 항목은 필드명과 토큰의 관계를 전달하며 비용 분류는 고정 enum으로 전달한다. 문서 주제도 고정된 업무 유형 목록으로만 전달한다. 기본 예시 검색 임베딩에는 그 고정 유형만 전송하며, 규정 검색 임베딩에도 고정 질의만 사용한다. 예시 본문은 코드에 등록된 가상 사례만 전달한다. 초안 모델 어댑터와 사례 검색 경계는 이 형식을 벗어난 직접 호출을 거부한다.

이는 개인정보 탐지기가 아니라 **입력 전체를 숨기는 보수적 방법**이다. 외부 서비스에는 토큰 개수와 배치, 날짜(현재 서버 기준), 고정 업무 유형·경비 분류, 가명 처리된 안정 식별자, 모델 정보와 가상 사례가 전달된다. 이 식별자는 같은 사용자의 요청을 연결할 수 있다. 실제 지출 등 입력 전체의 비밀성이 보장되는 것은 아니다. 이 경계는 결재 초안 생성·반려 경비 수정에 적용되며 별도의 업무 도우미·휴가 상담·AI 검토 기능 전체에 적용되는 것은 아니다. 사용자 입력과 복원된 미리보기는 사용자와 서버에서 계속 볼 수 있고, 화면·브라우저·애플리케이션 밖의 기록은 이 기능이 삭제하지 않는다. 요청 추적은 비활성화한다.

## 내용 대조와 한계

명시된 항목 입력과 일반 자연어 입력은 아래에 설명한 근거 기반 기안 경로를 사용한다. 그 외에는 AI 제목이 원문 한 줄과 정확히 일치하고 본문은 원문과 추가 답변의 모든 비어 있지 않은 줄을 같은 순서로 포함해야 한다. 조건이 맞지 않으면 모델 문장을 버리고 제목 `업무 기안`과 원문 기반 본문으로 미리보기를 구성한다. 일반 기안의 모델 추정 금액·출장·경비 필드는 제거한다. 이 검사는 **입력과의 문자 대응**이지 사실의 진위나 의미 전체의 검증은 아니다. 모델이 자연스럽게 바꿔 쓴 문장과 새 목차도 자동으로 배제되므로 일반 기안의 문장 다듬기·사례 활용은 크게 제한된다. 사용자는 화면에서 직접 다듬고 확인해야 한다. 출장 초안의 자유 본문에는 이 일반 기안 검증이 적용되지 않는다. 경비는 기존 필드별 원문 대응을 별도로 적용한다.

현재 결재선은 작성자의 활성 직속 상급자 1명이며, 제출 시 서버가 다시 확인한다. 다단계 결재선 선택은 지원하지 않는다. 공개 데모의 사례 검색은 비활성화되어 있고 공개 배포는 별도다.

## 로컬 준비와 평가

`pnpm db:migrate`, `pnpm db:seed`, `pnpm examples:index` 순서로 로컬 DB와 사례 인덱스를 준비한다. 마지막 명령은 가상 사례의 유료 임베딩 호출을 할 수 있다. 현재 로컬 인덱스는 생성되어 있다. 별도의 AI 기능 설정과 API 키가 필요하며, 설정이 꺼져 있으면 API 호출이 실행되지 않는다.

2026-10-30 개인정보 경계 적용 전의 실제 모델 합성 검색 12건은 상위 2건에 기대 유형이 12건 들어왔다. 이 수치는 원문 기반 검색의 이전 결과로, 고정 업무 유형 검색 품질을 뜻하지 않는다. 개인정보 경계 변경 후에는 `cd apps/api && uv run python -m app.evals.approval_examples`로 고정 유형 검색을 별도로 평가한다. 합성 요청이더라도 임베딩 API 비용이 발생한다. 소규모 수작업 평가는 실제 업무 정확도나 개인정보 보호 전체의 보증이 아니다.

2026-10-30 변경 후 합성 요청 12건을 같은 방식으로 시험하며 고정 유형 사전을 조정했고, 조정 후 기대 유형의 상위 2건 포함은 12건이었다. 동일 사례로 조정한 결과이므로 독립 평가가 아니다.

## 가상 데이터로 확인한 항목별 기안 경로

2026-10-30 후속 실험은 `문서 유형: 일반`과 `제목`, `개요`, `업무 내용`, `업무 기간`, `주요 산출물`, `참여 인원`처럼 **각 항목을 한 줄로 명시한 입력**에 적용된다. 예시에서 일치하는 항목명을 참고하되, 본문 값은 사용자가 입력한 원문 그대로이고 서버가 고정한 연결 문구만 추가한다. 모델이 생성한 문장과 구조화 금액 등은 사용하지 않는다. 각 항목의 원문·입력 순서·위치를 응답과 화면에 표시하며, 사용되지 않은 가상 사례의 항목은 선택적으로 보완하도록 표시한다. 입력에 없는 값을 AI나 사례에서 채우지 않는다.

항목 표시 없이 작성한 자연어는 아래 자연어 경로로 처리한다. 모르는 항목명, 같은 항목의 반복 등 모호한 라벨 입력은 기존 원문 기반 미리보기로 되돌린다. 현재 원문 밖의 사실을 의미적으로 판정하거나 자연어 문장을 자유롭게 재작성하는 시스템이 아니다. 실제 사실 여부, 작성자의 의도, 여러 입력의 모순은 사용자가 확인해야 한다. 원문의 여러 줄로 된 항목은 아직 지원하지 않는다. 원문 위치는 서버에서 앞뒤 공백을 제거한 요청과 빈 답변을 제외한 답변의 Unicode code point 기준이다.

선택형 `JHWORKS_LOCAL_EXAMPLE_SEARCH_ENABLED=true`는 서버에서 **127.0.0.1:11434**에 실행 중인 Ollama의 `bge-m3:latest`에 원문을 보내 유사 가상 사례를 검색한다. 연결 주소는 고정되어 있고 리디렉션하지 않는다. 가상 사례 임베딩만 프로세스 메모리에 캐시하며 사용자의 질의는 캐시하지 않는다. Ollama 및 모델의 로컬 설정과 로그는 별도의 관리 대상이다. 로컬 서버가 없거나 실패하면 외부 검색에는 고정 업무 유형만 전달하는 기존 방식으로 되돌리고 화면에 표시한다. 기본 설정은 OFF이며, 컨테이너에서는 루프백이 컨테이너 자신을 가리킨다. 모델·서버를 자동 다운로드하거나 시작하지 않는다.

합성 입력으로 실제 로컬 임베딩과 실제 외부 초안 모델을 함께 실행했으며, 로컬 검색 결과에서 인터뷰 사례 두 건을 찾고 6개 입력 근거가 원문 위치에 정확히 대응하는 미리보기를 반환했다. 기안의 사실은 서버가 원문에서 조합한 것이며 모델의 자유 문장 생성 품질을 검증한 결과는 아니다. 모델이 입력 밖 승인·금액을 제안한 합성 회귀, 누락 항목, 중복 정정, 원문 전송 경계와 로컬 검색 실패 대체 경로도 테스트했다. 이 검증은 작은 가상 사례로 실제 업무 정확도를 보장하지 않는다.

## 항목 표시 없는 자연어의 보수적 기안

일반 기안으로 분류된 자연어 입력은 항목 표기가 없어도 처리한다. 각 입력·답변의 비어 있지 않은 문장 구간을 서버에서 순서대로 보존하고, 명시적인 `기간은`, `참여자는`, `산출물은` 같은 문장 시작만 제한적으로 분류한다. 다른 문장은 업무 내용으로 둔다. 선택된 가상 사례에 같은 항목이 있으면 항목명을 참고했다고 표시한다. 문장 속 사실이나 사례의 내용을 덧붙이지 않으며 문장을 다른 순서로 옮기지 않는다.

정해진 문장 종결형 `했어/했어요`와 `이야/이에요`에 한해 정중한 말투로 치환하고, 각 문장의 원문·변환 결과와 원문 범위를 화면에서 보여준다. 질문형과 지원하지 않는 표현은 바꾸지 않으며 `아니야`를 긍정으로 바꾸지 않는다. 후속 답변에 정정 표현이 있거나 같은 명시적 항목에 서로 다른 값이 있으면 의미를 추측하지 않고 원문 기반 미리보기로 되돌린다. 라벨 입력이 불완전하거나 모호한 경우도 기존 보수 경로를 유지한다.

AI가 생성한 자유 문장이나 제목은 이 경로에 사용하지 않는다. 서버가 고정된 제목·항목과 원문 구간을 조합한다. 따라서 자연스러운 장문으로 의미를 재서술하는 기능이나 일반적인 의미 검증기는 아니다. 입력의 실제 진위, 모든 모순, 생략된 맥락을 확인할 수 없고, 서식·존댓말 변환도 사용자의 검토가 필요하다. 사용자가 말한 사실과 모델이 만든 문장을 구분하는 안전한 범위의 첫 단계다.
