# 결재 입력 보호 — M3-02C

## 사용 흐름

폼의 값이 처음 표시된 값과 달라지면 저장하지 않은 변경으로 판단한다. 일반 앱 링크와 취소 버튼은 확인 대화상자를 연다. 기본 포커스는 ‘계속 작성’이며 Esc도 같은 동작이다. ‘저장하지 않고 이동’을 명시하면 임시 입력을 지우고 이동한다. 저장·제출은 자동으로 실행하지 않는다.

저장 중에는 폼 필드·저장·취소를 비활성화하고 같은 이벤트의 중복 저장을 ref로 차단한다. 실패하면 기존 값을 그대로 유지하고 서버 오류를 알린다. 서버 성공 시에만 임시 입력을 제거하고 상세로 이동한다. 계정 세대가 바뀐 뒤 돌아온 이전 저장 응답과 이미 떠난 폼의 응답은 현재 화면을 이동시키지 않는다.

문서 상세→편집→저장/취소에서도 알려진 `mine`/`assigned` origin만 전달해 목록 복귀 범위를 유지한다. 외부 복귀 URL은 받지 않는다.

## 임시 입력 계약

| 경계 | 동작 |
| --- | --- |
| 저장 위치 | `sessionStorage`, 직원ID + 새 작성/문서ID별 키. 서버나 URL로 입력을 전송하지 않음 |
| 시작 | 초기 화면 값에서 실제로 변경했을 때. AI 전달/휴가 preset은 그 자체만으로 보관하지 않음 |
| 보관 | 마지막 변경부터15분, schema1·문서 기본 version·모든 폼 값의 구조 검사 |
| 한도 | 전체 JSON32,000자, 각 텍스트5,000자. 실패·초과 시 잘라내지 않고 안내 |
| 복원 | 같은 직원·문서·기본 version에서만 ‘이전 입력 이어쓰기’로 명시적 복원 |
| 새 입력·지우기 | 새로 작성하면 이전 보관값 대체. 지우기는 저장소와 복원 후보 제거 |
| 원래 값으로 되돌림 | 수정 중 생긴 임시 보관 삭제 |
| 저장 성공·이동 확인 | 해당 임시 보관 제거 |
| 로그아웃·확인된 계정 변경·세션 만료 | 기존 직원의 모든 임시 폼 제거, 페이지 상태 초기화 |
| 저장소 차단·quota·잘못된 JSON·만료·다른 version | 복원하지 않음. 저장 실패는 화면 입력과 서버 저장을 막지 않음 |

임시 입력은 초안 저장과 다르며 API 쓰기를 실행하지 않는다. 첨부 메타데이터·서버 version을 임시 입력으로 덮어쓰지 않는다. 만료는 읽을 때 검사하고 삭제한다. 브라우저 저장소는 권한 경계가 아니며 실제 개인정보·회사 자료 대신 합성 정보로 체험한다. 브라우저가 탭을 복제하면 sessionStorage 사본이 생길 수 있으므로 별도 보안 격리로 표현하지 않는다.

새로고침·탭 닫기는 브라우저 기본 beforeunload 확인을 사용한다. SPA 뒤로가기나 앱 외부 코드의 임의 router 호출을 history 변조로 강제 차단하지 않는다. 이 경우 해당 폼을 다시 열면 임시 입력의 명시적 복원으로 회복한다. 브라우저/OS의 강제 종료는 확인 표시를 보장하지 않는다. 인증 만료·로그아웃은 입력 경고로 막지 않는다.

## 구현과 재사용

`GuardedLink`는 Next의 onNavigate를 사용해 수정키 새 탭·다운로드·외부 링크의 기본 동작을 유지한다. 폼이 마운트된 동안만 navigation guard를 등록하고, 해제할 때 자기 guard만 제거한다. 홈 로고·사이드바가 이를 사용한다.

`ConfirmationDialog`를 이동 경고와 기존 제출·승인·반려·재작성의 공통 껍데기로 추출했다. native dialog, 취소 초기 포커스, Tab 순환, Esc 취소, 닫은 뒤 포커스 복원, busy 계약을 공유한다. 현재는 앱 내부 컴포넌트이며 npm 공개 API나 Storybook 완료를 뜻하지 않는다.

## 검증

`e2e/approval-form-recovery.spec.ts`는 PC·모바일에서 이동/Esc/포커스, 입력 복원과 무쓰기, 저장 실패·저장소 차단, 로그아웃·계정 변경·만료, 손상/만료 입력과 다른 version 거부, 편집 origin 왕복을 검증한다. production CI에도 포함한다. 기존 실제 경비 저장·수정·제출·승인과 AI 수동 전달 회귀를 함께 실행한다.

사람의 사용성 효과를 측정한 결과는 아니다. 공개 배포·AI 활성화·유료 호출·원격 정리는 포함하지 않는다.
